# Deck 參考 · 社區投稿指引（繁體中文 · 書面語）

本站採「先審核、後公開」。登入後投稿的牌組會進入待審核；通過下列檢查後方於 Deck 參考公開，公開後始可投票。

## A. 合法構築（任一項不符即拒稿）

1. 主牌組須為剛好 **50 張**角色卡。
2. 同名卡最多 **3 張**（異畫／再版視為同一名稱）。
3. 顏色最多 **2 種**。
4. 分享碼須可於 Deck Builder 匯入，並還原為相同牌表。
5. **不得**將 Rush Point 計入上述 50 張（Rush Point 另行計算）。

## B. 必填欄位

1. **牌組名稱**
2. **上載者顯示名稱**
3. **玩法描述**（見 C）
4. **合法分享碼**，或完整牌表

## C. 玩法描述最低標準

1. 須寫明主引擎：**觸發條件／卡 → 回報卡**（至少一條效果鏈）。
2. 以兩至四句說明前、中、後期用法。
3. 僅寫主題名稱（例如「蜘蛛主題」「復仇者」）而無機制說明者，不予通過。

### 合格範例

> 以 Synchronize／Leverage 提升 Range 或 Power，觸發 Fire Support 每回合削弱；再以 Ordnance Drop、Anti-Tank 疊加壓力。

### 不合格範例

> 很強的鋼鐵人卡組。

## D. 審核結果

| 標記 | 說明 |
|------|------|
| 通過（pass） | 構築與描述均符合本指引，予以公開 |
| 拒稿（reject） | 構築或描述不符；拒稿須註明對應 A 或 C 之條款 |
| 須修改（revise） | 構築合法，但玩法描述不足，請按意見修改後再提交 |

「**MHR 編輯群**」署名之牌組同樣須通過 A 與 C。upvote／downvote 僅於牌組公開後開放；每位登入用戶對每副牌組限一票。
